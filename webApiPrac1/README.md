# Практическая работа Модуль 01

## Тема

Введение в ASP.NET Core и первая конечная точка в API.

## Цель работы

Закрепить понимание принципов работы Web API, HTTP-запросов и HTTP-ответов, а также получить первый опыт проектирования REST API.

## 1. Предметная область и ресурс

В качестве предметной области выбраны **учебные курсы**.

Основной ресурс системы — `Course`. Он содержит следующие поля:

| Поле | Тип данных | Назначение |
|---|---|---|
| `Id` | `int` | Уникальный идентификатор курса |
| `Name` | `string` | Название курса |
| `Teacher` | `string` | Имя преподавателя |
| `Credits` | `int` | Количество кредитов |

## 2. Endpoints

### Получение всех курсов

- HTTP Method: `GET`
- URL: `/api/courses`
- Назначение: получить список всех учебных курсов.
- Возможный HTTP Status Code: `200 OK` — запрос выполнен успешно.

### Получение курса по идентификатору

- HTTP Method: `GET`
- URL: `/api/courses/{id}`
- Пример: `/api/courses/5`
- Назначение: получить один учебный курс по его идентификатору.
- Возможные HTTP Status Codes:
  - `200 OK` — курс найден;
  - `404 Not Found` — курс с указанным идентификатором отсутствует.

### Создание курса

- HTTP Method: `POST`
- URL: `/api/courses`
- Назначение: создать новый учебный курс.
- Возможные HTTP Status Codes:
  - `201 Created` — курс успешно создан;
  - `400 Bad Request` — переданы некорректные данные.

## 4. Ответы на вопросы

### 1. Что такое Web API

Web API — это программный интерфейс, через который приложения обмениваются данными по сети. Клиент отправляет HTTP-запрос, а сервер обрабатывает его и возвращает ответ, часто в формате JSON.

### 2. В чём разница между HTTP Request и HTTP Response

HTTP Request — это запрос клиента к серверу. Он содержит HTTP-метод, URL, заголовки и при необходимости тело запроса. HTTP Response — это ответ сервера, содержащий статусный код, заголовки и данные.

### 3. Для чего используется GET

Метод `GET` используется для получения данных с сервера. Например, с его помощью можно получить список всех курсов или один курс по идентификатору.

### 4. Для чего используется POST

Метод `POST` используется для отправки данных на сервер и создания нового ресурса. В данном API он применяется для добавления нового учебного курса.

### 5. Что означают 200 OK и 404 Not Found

`200 OK` означает, что запрос успешно обработан сервером. `404 Not Found` означает, что запрашиваемый ресурс не найден, например курс с указанным идентификатором отсутствует.
